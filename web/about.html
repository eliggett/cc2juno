cc2juno

Turns the knobs on an ordinary MIDI controller into real-time edits for a Roland Alpha Juno 1, Alpha Juno 2 or MKS-50.

cc2juno is by Elliott Liggett with enormous contributions made by Claude Opus 5. This is open source software; the repo is https://github.com/eliggett/cc2juno

The classic Alpha Juno synths require menu diving to adjust, and they do not respond to ordinary MIDI CC messages. Everything on the front panel is reached by paging through a menu, and the only way in from outside is MIDI system exclusive (sysex). Roland sold the PG-300 programmer to solve that, but these are becoming rare and expensive. cc2juno does the same job with whatever CC controller you already own: it listens for the CCs your knobs send, converts each one into the sysex message for the tone parameter you assigned it, and passes anything it does not recognise straight through. The web interface takes this further by allowing on-screen parameter editing with the appearance of the classic PG-300.

All 36 tone parameters are available. A controller with fewer knobs than that can give one knob up to choosing a layer, which swaps what every other knob does — so eight knobs and a layer selector can still reach the whole synth.

Configurations are ordinary text files. The one this page exports is the same file used by the command-line version and by the build for the Tulip Creative Computer, so a mapping worked out here will run on a Raspberry Pi with no screen attached, and one worked out there opens here.

Patches

Patch Manager opens a bank file — the ordinary .syx dump any Alpha Juno librarian writes, or a .mid with that dump saved inside it — and lists what is in it. Several files can be open at once, and a file holding several banks is browsed a bank at a time rather than having all but one of them quietly discarded. Click a patch and the synth plays it straight away; drag it into the left-hand pane to build a set, rename and reorder it there, and write all 64 back to the instrument in one go. A dump can be pulled off the synth the same way, edited, and sent back.

Live Patch keeps the controls on screen and puts the same list beside them. Clicking a patch loads it into the synth's edit buffer and moves every control to match, so a file of 64 sounds can be played straight from disk without writing anything to the instrument's memory. Once a set has been built or a dump received, a switch above the list offers that as well, so either can be played from. The display shows T and the patch's number in the file, because that is the truth of it: the sound is only in the edit buffer, and the synth has no idea which patch of ours it is. To keep one, press WRITE on the synth while it is playing.

Getting sound out of it

Two things must be set on the synth itself, and nothing works until they are: sysex receive must be ON (under the MIDI button on an Alpha Juno), and the synth's basic channel must match the synth channel set on this page.
