No knobs yet. Set the grid size, then click a cell and press Learn while moving the control you want there.

Knob

Press Learn, then move the control. It must travel 6 counts, so brushing past a neighbour will not grab it.

The layer knob means the same thing on every layer, so it can never also be a parameter.

Knob grid

16 knobs in a row is 1 × 16; three rows of four is 3 × 4. Knobs keep their reading order when the grid is reshaped.

Layers

A stray layer change is more disruptive than a stray enum flip, so this can be wider than the general dead zone. Blank follows it.

MIDI

The Roland/PG-300 charts give 0x20 / 0x01. If the synth ignores everything, try a level byte of 0x01.

Forward notes, bend, aftertouch and unmapped CCs to the output, so one keyboard can play the synth and edit it. Mapped CCs are consumed.
